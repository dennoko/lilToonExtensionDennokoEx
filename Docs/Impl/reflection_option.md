髪の毛のシェーダーにおける光沢（ハイライト）表現は、一般的な不透明オブジェクトの反射（Blinn-PhongやGGX）とは異なり、「異方性反射（Anisotropic Reflection）」という考え方がベースになります。

髪の毛は細い繊維の集合体であるため、光は表面の法線（Normal）ではなく、髪の繊維の方向（Tangent）に沿ってリング状に広がる性質があるからです。

一般的に採用される技法と、実装に組み込むべきロジック・オプションを整理しました。

---

## 1. 採用すべき主要な技法

### Kajiya-Kay Model

リアルタイム描画において最も一般的で軽量なモデルです。通常のスペキュラが「法線とハーフベクトルの内積」を使うのに対し、Kajiya-Kayは「接線（Tangent）とハーフベクトルの関係」を利用します。

**ロジック:**
反射強度は、接線 $T$ とハーフベクトル $H$ の角度の正弦（sine）に基づいて計算されます。


$$Specular = \sin(T, H)^p = \sqrt{1 - (T \cdot H)^2}^p$$


※ $p$ は光沢の鋭さ（Shininess）です。

### Scheuermann's Method

Kajiya-Kayを拡張し、ハイライトを2重にする技法です。

* **第一ハイライト:** 直接的な反射（白っぽい光）。
* **第二ハイライト:** 髪の内部で反射して色付いた光（少し位置をずらす）。

これにより、単なる塗りつぶしではない、奥行きのある質感が生まれます。

## 2. 追加すべきオプションとパラメータ

シェーダーのプロパティ（Inspector）に追加すると効果的な項目です。

### ① Tangent Shift（位置調整）

髪のキューティクルには微細な傾きがあるため、ハイライトは物理的に少し「ズレ」が生じます。これを制御するために**Shift値**を導入します。

* **ロジック:** $T' = T + (Normal \times Shift)$
* **用途:** テクスチャ（ノイズマップ）を使って場所ごとにShift値を変えると、ハイライトが一直線にならず、髪の束感が出ます。

### ② Dual Specular（2重ハイライト）

* **Primary Specular:** 鋭く明るい反射。
* **Secondary Specular:** 髪のベースカラーを反映した、少しぼやけた反射。
* **Offset:** 1つ目と2つ目のハイライトをどれだけ上下に離すか。

### ③ Anisotropic Noise（異方性ノイズ）

ハイライトの輪郭をあえて「散らす」ための設定です。

* **用途:** 完全に滑らかなリングではなく、一本一本の繊維が光っているような「ザラつき」を表現します。

## 3. 実装のロジック構成（疑似コード的考え方）

Unityなどのシェーダーで実装する場合、以下のフローをフラグメントシェーダーに組み込むのが理想的です。

1. **Tangentの取得:** メッシュの接線、またはUVに基づいた方向ベクトル。
2. **Shiftの適用:**
```hlsl
// ノイズマップ等でTangentを法線方向にオフセットさせる
float shiftTex = tex2D(_HairShiftMap, uv).r - 0.5;
float3 shiftedTangent = T + (N * (_PrimaryShift + shiftTex));

```


3. **Kajiya-Kayの計算関数:**

```hlsl
    float HairSpecular(float3 T, float3 H, float exponent) {
        float dotTH = dot(T, H);
        float sinTH = sqrt(1.0 - dotTH * dotTH);
        float dirAtten = smoothstep(-1.0, 0.0, dotTH);
        return dirAtten * pow(sinTH, exponent);
    }
    ```
4.  **合成:**
    *   Primary（白） + Secondary（髪の色に近い色）を合算して最終的な出力にします。

## 4. さらにこだわりたい場合：スタイライズド（アニメ調）への応用

もしVRChat向けなどのアニメ調シェーダー（Toon Shader）であれば、上記の計算結果を `step` 関数や `smoothstep` で閾値処理してください。

*   **天使の輪（Angel Ring）:** UV座標のV（垂直方向）を固定値でマスクすることで、常に頭の特定の高さにハイライトが出るように固定する手法も一般的です。
*   **Matcapの併用:** 複雑な計算を避けつつ、特定の角度から見たときだけ光沢を乗せる手法です。
